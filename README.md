# ALL STAR FIGHT

Jeu de combat style Bleach vs Naruto (persos faits à partir de skins Minecraft).
2 joueurs en local, contre le CPU, ou EN LIGNE via Supabase.

## Jouer en ligne
1. Crée un projet gratuit sur https://supabase.com
2. Project Settings → API : copie le *Project URL* et la clé *anon public*
3. Dans `index.html`, cherche `SUPABASE_URL` et colle les deux valeurs (ou entre-les dans le jeu, menu EN LIGNE)
4. Mets le site sur GitHub Pages, partage le lien
5. Menu EN LIGNE → un joueur crée un salon, l'autre entre le code à 4 lettres
